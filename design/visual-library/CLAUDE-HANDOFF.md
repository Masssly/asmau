You are helping develop a reusable visual asset library for Asmau, an Islamic learning games project for children.

## Project owner's approved direction

The owner approved the initial concept board and wants:
- A playable, immersive 3D adventure-game visual language.
- Black African human characters.
- A strong Hausa-Fulani / West African Muslim visual foundation, informed by the historical Sokoto region and Usman dan Fodio's era.
- Future Asmau games to draw from a shared, coherent character and environment library.
- A stylised-realism approach rather than generic cartoon visuals.
- A reusable library that can eventually be shared by multiple games.

## Important historical and religious constraints

The Yusuf story is associated with ancient Egypt. The Sokoto Caliphate is much later. Do not claim that Sokoto clothing or architecture is historically accurate for Yusuf's time. Treat those references as a deliberate artistic influence unless a particular game is explicitly set in the later West African period.

Do not depict Prophet Yusuf directly. Use environment, objects, point-of-view framing and other characters' reactions to tell the story.

## Work requested

Develop this folder in isolation. Do not modify the game runtime, homepage, shared scripts or existing game directories unless the owner explicitly asks.

Start with a production-ready design package, not a broad game implementation:
1. Refine the character style sheet.
2. Produce consistent front/side/back turnaround sheets for one child and one adult character.
3. Produce expression sheets and clothing/material callouts.
4. Create a small modular Sahelian compound/courtyard environment kit.
5. Provide clean source files and game-ready exports when 3D assets are produced.
6. Update the manifest and provenance/credits for every asset.

## Technical expectations

- Prefer Blender source plus optimised GLB exports.
- Use consistent scale, pivots, naming and texture conventions.
- Keep mobile/tablet performance in mind.
- Include low-detail alternatives where useful.
- Do not claim compatibility or performance without testing.
- Keep assets modular and reusable.

## Review checkpoints

Do not generate dozens of characters before the owner approves the first character turnaround. Do not expand the cultural scope without documenting the region and period of each reference. Present small batches for review.
